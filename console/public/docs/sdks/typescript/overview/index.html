TypeScript and JavaScript SDK for Mojobase

Install and initialize the official Mojobase TypeScript SDK in Node, browsers, and edge runtimes to use auth, database, storage, and realtime.

The Mojobase TypeScript SDK provides a type-safe client for interacting with Mojobase services from JavaScript and TypeScript applications.

#Installation

bash
npm install @mojobase/sdk@latest
bash
yarn add @mojobase/sdk@latest
bash
pnpm add @mojobase/sdk@latest
javascript
import { createClient } from '@mojobase/sdk';

const mojobase = createClient({
  baseUrl: 'https://your-project.mojobase.dev',
  anonKey: 'your-anon-key'  // Optional: for public/unauthenticated requests
});

Find the project URL and anon key in your project's Connect panel in the Mojobase console.

#Quick start

typescript
import { createClient } from '@mojobase/sdk';

const mojobase = createClient({

#Features

  • Database - Type-safe CRUD operations with PostgREST
  • Authentication - Email/password and OAuth authentication
  • Storage - File upload, download, and management
  • Functions - Invoke serverless edge functions
  • AI - Chat completions and image generation
  • Realtime - WebSocket-based pub/sub messaging
  • Payments - Provider-scoped Stripe and Razorpay payment helpers
