TypeScript

Storage SDK Reference

Upload, download, list, and delete files in S3-compatible Mojobase buckets from browser or Node.js apps with the Mojobase TypeScript SDK storage client.

#Installation

bash
npm install @mojobase/sdk@latest
bash
yarn add @mojobase/sdk@latest
bash
pnpm add @mojobase/sdk@latest
javascript
import { createClient } from '@mojobase/sdk';

const mojobase = createClient({
  baseUrl: 'https://your-project.mojobase.dev',
  anonKey: 'your-anon-key'  // Optional: for public/unauthenticated requests
});

Find the project URL and anon key in your project's Connect panel in the Mojobase console.

#from()

Get a bucket instance for file operations.

#Parameters

  • bucketName (string, required) - Name of the storage bucket

#Returns

typescript
StorageBucket // Instance with upload, uploadAuto, download, remove methods

#Example

javascript
const bucket = mojobase.storage.from('images')

#upload()

Upload a file with a specific path/key.

#Parameters

  • path (string, required) - The object key/path for the file
  • file (File | Blob, required) - File or Blob to upload

#Returns

typescript
{
  data: {
    bucket: string,
    key: string,
    size: number,
    mimeType: string,
    uploadedAt: string,
    url: string
  } | null,
  error: Error | null
}
i

Uploading to an existing key replaces the current object. Use uploadAuto() when you want a unique key generated automatically.

#Example

javascript
const { data, error } = await mojobase.storage
  .from('images')
  .upload('posts/post-123/cover.jpg', fileObject)

// Save BOTH url and key to database
await mojobase.database
  .from('posts')
  .update({
    image_url: data.url,
    image_key: data.key  // Save key for download/delete operations
  })
  .eq('id', 'post-123')

#Output

json
{
  "data": {
    "bucket": "images",
    "key": "posts/post-123/cover.jpg",
    "size": 45678,
    "mimeType": "image/jpeg",
    "uploadedAt": "2024-01-15T10:30:00Z",
    "url": "https://your-project.mojobase.dev/api/storage/buckets/images/objects/posts%2Fpost-123%2Fcover.jpg"
  },
  "error": null
}

#uploadAuto()

Upload a file with auto-generated unique key.

#Parameters

  • file (File | Blob, required) - File or Blob to upload

#Returns

typescript
{
  data: {
    bucket: string,
    key: string,
    size: number,
    mimeType: string,
    uploadedAt: string,
    url: string
  } | null,
  error: Error | null
}

#Example

javascript
const { data, error } = await mojobase.storage
  .from('uploads')
  .uploadAuto(fileObject)

// Save url and key to database
await mojobase.database
  .from('posts')
  .insert([{
    image_url: data.url,
    image_key: data.key,  // Save key for download/delete operations
    user_id: userId
  }])

#Output

json
{
  "data": {
    "bucket": "uploads",
    "key": "myfile-1705315200000-abc123.jpg",
    "size": 45678,
    "mimeType": "image/jpeg",
    "uploadedAt": "2024-01-15T10:30:00Z",
    "url": "https://your-project.mojobase.dev/api/storage/buckets/uploads/objects/myfile-1705315200000-abc123.jpg"
  },
  "error": null
}

#download()

Download a file as Blob.

#Parameters

  • path (string, required) - The object key/path to download

#Returns

typescript
{
  data: Blob | null,
  error: Error | null
}

#Example

javascript
// 1. Get the file key from your database
const { data: post, error: dbError } = await mojobase.database
  .from('posts')
  .select('image_key')
  .eq('id', 'post-123')
  .single()

// 2. Download the file using the key
const { data: blob, error } = await mojobase.storage
  .from('images')
  .download(post.image_key)

// 3. Create download link or display image
const url = URL.createObjectURL(blob)
const img = document.querySelector('img')
img.src = url

#Output

json
{
  "data": "Blob { size: 45678, type: 'image/jpeg' }",
  "error": null
}

#remove()

Delete a file from storage.

#Parameters

  • path (string, required) - The object key/path to delete

#Returns

typescript
{
  data: { message: string } | null,
  error: Error | null
}

#Example

javascript
// 1. Get the file key from your database
const { data: post, error: dbError } = await mojobase.database
  .from('posts')
  .select('image_key')
  .eq('id', 'post-123')
  .single()

// 2. Delete the file from storage
const { data, error } = await mojobase.storage
  .from('images')
  .remove(post.image_key)

// 3. Clear the database reference
await mojobase.database
  .from('posts')
  .update({ image_url: null, image_key: null })
  .eq('id', 'post-123')

#Output

json
{
  "data": {
    "message": "Object deleted successfully"
  },
  "error": null
}
