Quickstart

Quickstart

Create a Mojobase project, connect your app or coding agent, and make your first database call in a few minutes.

#Step 1: Create a project

  1. Sign up

    Go to mojobase.dev and create a free account (verify your email if asked).

  2. Create a project

    Click New project, give it a name, and wait about a minute while its backend (Postgres, auth, storage, functions, realtime) is provisioned.

  3. Open Connect

    When the project is ready, click Connect. You'll see the Project URL, the Anon key (anon_...), the admin API key (ik_...) and the Postgres connection string.

#Step 2: Connect your coding agent

The fastest path: click the project's AI prompt button and paste the prompt into Claude Code, Cursor, Codex, Windsurf, Copilot or any coding agent, inside your app's folder. The prompt contains your real project URL, keys and connection string plus instructions for schema, security, auth, database, storage, functions and realtime, so the agent can wire the backend into your app without asking you for anything.

To let the agent manage your backend directly (create tables, run SQL, deploy functions), also connect it over MCP:

Create a personal access token (mbp_...) at mojobase.dev/agents, then add the server. For Claude Code:

bash
claude mcp add --transport http mojobase https://mojobase.dev/mcp \
  --header "Authorization: Bearer mbp_your_token"

The agent can now list and create projects, run SQL, manage buckets and functions, and fetch connection details. See MCP setup for Cursor, Windsurf, VS Code and others.

Install the project-scoped MCP server into your client with your project's admin API key:

bash
npx @mojobase/install --client claude-code \
  --env API_KEY=ik_your_api_key \
  --env API_BASE_URL=https://your-project.mojobase.dev

Replace claude-code with cursor, windsurf, vscode, codex and so on. See MCP setup.

#Step 3: Or wire the SDK yourself

bash
npm install @mojobase/sdk
bash
yarn add @mojobase/sdk
bash
pnpm add @mojobase/sdk
lib/mojobase.ts
import { createClient } from '@mojobase/sdk';

export const mojobase = createClient({
  baseUrl: 'https://your-project.mojobase.dev',
  anonKey: 'anon_your_anon_key',
});

Create a table from the dashboard's SQL Editor (or let your agent do it), then query it:

sql
create table public.todos (
  id uuid primary key default gen_random_uuid(),
  title text not null,
  done boolean not null default false,
  user_id uuid default auth.uid() references auth.users(id) on delete cascade
);
alter table public.todos enable row level security;
create policy "own todos" on public.todos
  for all to authenticated using (user_id = auth.uid()) with check (user_id = auth.uid());
typescript
const { data, error } = await mojobase.database.from('todos').select('*');

Every SDK call returns { data, error }. Keep the ik_ API key and the connection string on the server: the anon key is the only one that belongs in browser code.
