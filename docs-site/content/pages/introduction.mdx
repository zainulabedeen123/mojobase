Every Mojobase project is a complete backend with its own URL (`https://your-project.mojobase.dev`): a Postgres database with an instant REST API, authentication, file storage, edge functions, realtime channels, a model gateway, email and payments. Build against it from your app with the SDK, or let your coding agent drive it over MCP.

## Keys at a glance

| Value | Looks like | Where to use it |
|---|---|---|
| Project URL | `https://your-project.mojobase.dev` | Everywhere |
| Anon key | `anon_...` | Browsers and mobile apps. Row-level security decides what each user can do. |
| API key (admin) | `ik_...` | Server-side code and admin scripts only. Bypasses row-level security. |
| Connection string | `postgresql://mojobase:<password>@db.mojobase.dev:<port>/insforge?sslmode=require` | Server-side tools, ORMs and migrations only. |

All of them are in your project's **Connect** panel in the [Mojobase console](https://mojobase.dev).
